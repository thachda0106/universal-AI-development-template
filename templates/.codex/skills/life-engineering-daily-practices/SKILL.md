# Skill: life-engineering-daily-practices

## When to Use

Use this skill when you need to systematically manage your daily life using engineering principles. This is NOT for generic self-improvement — it is for engineers who want to treat their mind, body, and life as a production system requiring active maintenance, observability, and architecture.

Apply this skill for:
- **Daily system maintenance** (morning boot, evening shutdown)
- **Performance optimization** (deep focus, energy management)
- **Debugging** (emotional anomalies, cognitive distortions)
- **Incident response** (crises, failures, conflicts)
- **Architecture review** (weekly planning, life refactoring)
- **Decision logging** (structured decision-making with traceability)

## Core Philosophy

Human life is:
- A **complex adaptive system** operating in a probabilistic environment
- An **event-driven architecture** with unreliable inputs
- A **stateful runtime** with limited compute resources (attention, energy, willpower)
- A **distributed system** where different subsystems must reach consensus
- A **production system** running 24/7 with no SLA, no failover, and a single point of failure

## Daily Practice Areas

1. **Morning System Boot** — Initialize daily state, allocate attention budget, set intention
2. **Evening System Shutdown** — Collect metrics, review patterns, prepare recovery
3. **Deep Focus Session** — Single-threaded execution, eliminate interrupts
4. **Emotional Observability** — Check emotional state, detect anomalies, regulate
5. **Cognitive Scan** — Detect distortions and biases, reframe, calibrate
6. **Energy Audit** — Track energy, identify drains, optimize allocation
7. **Weekly Architecture Review** — Aggregate metrics, assess debt, plan next week
8. **Incident Response** — Handle crises with structured incident protocol
9. **Decision Log** — Log decisions with rationale, expected value, follow-up
